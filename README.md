# CodeAlpha C++ Programming Internship Tasks

This repository contains a collection of C++ applications developed during my internship at **CodeAlpha**. These projects demonstrate proficiency in Object-Oriented Programming (OOP), algorithmic thinking, data persistence, and robust user-input handling.

---

## 🚀 Projects Overview

### 1. Banking System
A comprehensive management tool utilizing **Object-Oriented Programming** principles.
* **Key Features:** Account creation, secure deposits/withdrawals, and inter-account transfers.
* **Technical Highlights:** Implements a `Transaction` class for history tracking and uses `std::vector` for dynamic account management.

### 2. Sudoku Solver
A logic-based puzzle solver powered by the **Backtracking Algorithm**.
* **Key Features:** Real-time grid validation and automated solving.
* **Technical Highlights:** Uses recursive functions to explore possible solutions and state-restoration to "backtrack" when paths fail.


### 3. CGPA Calculator
An academic performance tracker for students to monitor their progress.
* **Key Features:** Calculates individual Semester GPA and overall Cumulative GPA.
* **Technical Highlights:** Handles weighted calculations based on credit hours and uses `iomanip` for precise decimal formatting.

### 4. Login and Registration System
A security-focused console application for user authentication.
* **Key Features:** User registration with credential validation and local file storage.
* **Technical Highlights:** Utilizes **File I/O** (`fstream`) to persist user data across sessions and includes character-level input validation.
